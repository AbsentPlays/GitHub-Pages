Server Features

  • No Raiding / No PvP: Safe building environment.
  • Custom Monuments: Unique PvE challenges & bosses.
  • 2x Gathering Rates: Standard resources are slightly boosted.
  • Backpacks & QoL: Extra storage space on death.
  • Purge Event: Optional PvP active 24 hours prior to map wipe.

Server Rules

  • Respect all players; zero tolerance for toxicity or hate speech.
  • No raiding or stealing from other players' bases.
  • Do not lock off or hoard public monuments.
  • No cheating, exploiting, or taking advantage of bugs.
  • Limit base sizes to prevent server performance issues.
