# GitHub-Pages

Welcome to the official repository for my GitHub Pages website! You will find different GitHub pages that are free to use for anyone.

---

## 🛠️ Step-by-Step Setup Guide

### Setting up GitHub Pages

1. Create a new public repository on GitHub named `portfolio` or `username.github.io`.
2. Upload the `index.html` file into the main branch of this repository.
3. Go to **Settings** > **Pages** inside your repository.
4. Under **Build and deployment** > **Branch**, select `main` (or `master`) and click **Save**.
5. Your live site will be ready in 1–2 minutes at `https://YOUR_USERNAME.github.io/repository-name`.
