# 🌌 Cosmic Order — OSRS Clan Landing Page

A lightweight, single-page landing website built for **Cosmic Order**, an Old School RuneScape (OSRS) Social and PvM clan[cite: 2]. Features a cosmic nebula background, interactive raid tabs, a leadership roster display, and an applicant modal form[cite: 2].

---

## ✨ Features

* **Embedded SVG Favicon:** Built-in Cosmic Rune SVG favicon requiring no extra asset requests[cite: 2].
* **Interactive PvM Showcase:** Tabbed interface detailing recommendations and requirements for CoX, ToA, ToB, and mentorship[cite: 2].
* **Application Modal:** Popup form collecting applicant RSN, Discord username, and account type[cite: 2].
* **Pure HTML/CSS/JS:** Built without dependencies or frameworks for fast loading speed and straightforward hosting on GitHub Pages[cite: 2].
* **Responsive Layout:** Adaptive styling with breakpoint handling for desktop and mobile devices[cite: 2].

## 🚀 Quick Start & Customization

### 1. Clone the Repository

```bash
git clone https://github.com/cosmicorderosrs/cosmicorderosrs.github.io.git
cd cosmicorderosrs.github.io

```

### 2. Update Placeholders in `index.html`

Open `index.html` in your editor and update the following placeholders:

* **Discord Invite Link:** Replace `[https://discord.gg/YOUR_DISCORD_LINK](https://discord.gg/YOUR_DISCORD_LINK)` with your active invite link[cite: 2].
* **Header Banner:** Ensure your banner image is stored at `images/cosmic-banner.png` (or update line 223 to match your image path)[cite: 2].
* **Leadership Names:** Update `[Your RSN]`, `[Deputy 1]`, `[Mod 1]`, and `[Event Coordinator]` under the `#ranks` section with your actual staff RSNs[cite: 2].

### 3. Deploy to GitHub Pages

1. Push your repository to GitHub[cite: 1].
2. In your repository, navigate to **Settings** > **Pages**[cite: 1].
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and folder `/ (root)`[cite: 1].
4. Save your configuration. Your site will be published at `https://<your-username>.github.io/<repo-name>/`[cite: 1].
