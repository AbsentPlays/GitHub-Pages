# 🌌 Cosmic Order — OSRS Clan Landing Page

A lightweight, single-page landing website built for **Cosmic Order**, an Old School RuneScape (OSRS) Social and PvM clan. Features a cosmic nebula background, interactive raid tabs, a leadership roster display, and an applicant modal form.

---

## ✨ Features

* **Embedded SVG Favicon:** Built-in Cosmic Rune SVG favicon requiring no extra asset requests.
* **Interactive PvM Showcase:** Tabbed interface detailing recommendations and requirements for CoX, ToA, ToB, and mentorship.
* **Application Modal:** Popup form collecting applicant RSN, Discord username, and account type.
* **Pure HTML/CSS/JS:** Built without dependencies or frameworks for fast loading speed and straightforward hosting on GitHub Pages.
* **Responsive Layout:** Adaptive styling with breakpoint handling for desktop and mobile devices.

## 🚀 Quick Start & Customization

### 1. Clone the Repository

### 2. Update Placeholders in `index.html`

Open `index.html` in your editor and update the following placeholders:

* **Discord Invite Link:** Replace `[https://discord.gg/YOUR_DISCORD_LINK](https://discord.gg/YOUR_DISCORD_LINK)` with your active invite link.
* **Header Banner:** Ensure your banner image is stored at `images/cosmic-banner.png` (or update line 223 to match your image path).
* **Leadership Names:** Update `[Your RSN]`, `[Deputy 1]`, `[Mod 1]`, and `[Event Coordinator]` under the `#ranks` section with your actual staff RSNs.

### 3. Deploy to GitHub Pages

1. Push your repository to GitHub.
2. In your repository, navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Save your configuration. Your site will be published at `https://<your-username>.github.io/<repo-name>/`.
